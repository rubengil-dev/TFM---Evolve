# config/
Settings and data written by hand, apart from the logic:

- `errors.ts`: Texts of each error screen.
- `example.ts`: `?demo=` links (result, older, odd_value, impossible, impossible_bmi, too_young, too_old, unreadable, too_few, unavailable) that open a screen directly, with made-up data.
- `groups.ts`: Groups shown in the result tables.
- `limits.ts`: Numbers repeated from the backend config; a test checks they match.
- `questions.ts`: Questions asked after the PDF, with their options, ranges and the mode they belong to.
- `variables.ts`: Name shown for each value of the blood test.

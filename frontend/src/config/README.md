# config/
Settings and data written by hand, apart from the logic:

- `errors.ts`: Texts of each error screen.
- `example.ts`: Made-up data until the backend is connected, and `?demo=` links (result, older, odd_value, impossible, too_young, unreadable, too_few) that open a screen directly.
- `groups.ts`: Groups shown in the result tables.
- `questions.ts`: Questions asked after the PDF, with their options, ranges and the mode they belong to.

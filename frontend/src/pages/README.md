# pages/
One file per screen:

- `Landing.tsx`: Home screen; title and the two buttons that pick the mode and open the file picker.
- `Loading.tsx`: Short wait before the result: a DNA helix builds itself while a percentage climbs.
- `Questionnaire.tsx`: Questions one per screen: body measures in both modes, habits in the full mode.
- `Result.tsx`: Biological age with its margin, the gap to the real age, the tables of years and share / download.
